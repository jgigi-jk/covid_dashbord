สถานะการเชื่อมต่อ CSV: พร้อมใช้งาน

การติดตั้งลงบน GitHub Pages

ขั้นตอนการใช้งานบน GitHub Pages:

  1. สร้าง Repository ใหม่ใน GitHub (เช่น health-dashboard)
  2. เซฟโค้ดนี้ทั้งหมดไว้ในไฟล์ชื่อ index.html
  3. Upload ไฟล์ index.html ขึ้นสู่ GitHub Repository
  4. ไปที่ Settings > Pages เลือก Branch เป็น main แล้วกด Save
  5. เปิดใช้งาน URL Dashboard ทางเว็บได้ทันที!

หมายเหตุเกี่ยวกับข้อมูล CSV: ระบบจะทำการอ่านข้อมูลแบบ Real-time จากลิงก์ Google Sheets CSV ที่กำหนดไว้ในระบบโดยอัตโนมัติ
